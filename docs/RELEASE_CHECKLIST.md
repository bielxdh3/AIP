# Candidate checklist

- Do not publish, tag, sign, upload, or push from this checklist.
- Preserve the local data directory during updates and uninstall.
- RAID mirroring is not a backup; keep versioned backups separately.
- Verify the package contains no databases, logs, models, media, exports, or credentials.
- Complete `V0_1_MANUAL_VALIDATION.md` before approving a release.

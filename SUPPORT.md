# Support

AIP is under active development and does not provide a commercial support SLA.

## Bugs

Use the GitHub bug-report form with:

- AIP version or commit;
- operating system;
- affected component;
- reproduction steps;
- relevant runtime/model information;
- sanitized logs when useful.

Remove credentials, private conversations, memories, local databases, personal paths, and other sensitive data before posting.

## Feature requests

Use the feature-request form and explain the user problem first. Keep roadmap proposals separate from bug reports.

## Setup and usage

Start with:

- [README.md](README.md)
- [docs/WINDOWS_SETUP.md](docs/WINDOWS_SETUP.md)
- [docs/KNOWN_LIMITATIONS.md](docs/KNOWN_LIMITATIONS.md)
- [docs/ROADMAP.md](docs/ROADMAP.md)

If the documentation does not answer the problem, open an issue with the minimum safe information needed to reproduce it.

## Security

Do not report vulnerabilities in a public support issue. Follow [SECURITY.md](SECURITY.md).
